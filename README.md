# ねこおき 🐱 - 猫のロジックパズル

すべての行・列・エリアに猫を1匹ずつ。考えれば必ず解ける、猫のロジックパズルです。
スマホのホーム画面に追加して PWA(オフライン対応)として遊べます。

## あそびかた

- すべての **行**・**列**・**同じ色のエリア** に猫を **1匹ずつ** 置きます
- 猫どうしは **ななめもふくめて** となり合ってはいけません
- マスをタップすると 空マス → ×印(メモ)→ 猫 の順に切り替わります
- 運は不要。すべての問題は唯一解で、論理だけで解けます

## 特徴

- 📱 スマホ最適化・タップだけで完結
- 🔁 問題はその場で自動生成(無限に遊べる)
- 🧩 5×5 〜 9×9 の5段階。前のサイズをクリアすると次が解放
- 📴 PWA 対応でオフラインでも遊べる
- 💾 中断しても続きから再開(localStorage)

## GitHub Pages での公開手順

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を **GitHub Actions** に設定する
3. `main` ブランチに push すると `.github/workflows/pages.yml` が自動デプロイ

公開 URL: `https://<ユーザー名>.github.io/catpuzzle/`

## スマホアプリとして使う(PWA)

- **iOS (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「アプリをインストール」(または「ホーム画面に追加」)

## 技術メモ

- 依存ライブラリなし(Vanilla JS / ビルド不要)
- 問題生成: ランダムに猫の正解配置を作り、重み付きランダム成長でエリア分割 →
  バックトラックソルバーで**唯一解**であることを検証(不合格なら再生成)
- 9×9 でも生成は平均数ミリ秒
